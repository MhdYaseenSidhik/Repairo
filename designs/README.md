# Designs

Drawings, floor plans, diagrams, elevations and renders for the house live here.

## What goes here

- Floor plans (`.png`, `.svg`, `.pdf`, or diagram source)
- Elevations and sections
- Site / landscape plans showing the building on the 5-acre plot
- Massing diagrams and concept sketches
- Renders

## Conventions

- Name files with a kind prefix and a version, e.g.
  `floorplan-ground-v1.svg`, `site-plan-v2.png`, `elevation-south-v1.pdf`.
- Keep editable source (diagram XML, `.excalidraw`, `.drawio`) alongside exported images.
- Reference the drawing from the relevant doc in [`../docs/`](../docs/).
